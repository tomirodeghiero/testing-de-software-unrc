# Material transversal

Recursos comunes a toda la materia **Testing de Software** (UNRC). El material específico de cada práctico vive en `tpN/material/`.

## Contenido

- `Introduction to Software Testing.pdf` — Ammann & Offutt, libro principal de la cátedra.
- `cuestionario_general.pdf` / `.tex` — cuestionario integrador de la materia.

## Mapa de capítulos del libro por práctico

| Capítulo | Tema | Práctico |
| :---: | :--- | :---: |
| 1–2 | Conceptos básicos, *fault/error/failure*, modelo RIPR | TP1 |
| 8 | Testing de expresiones lógicas (predicados, cláusulas, CACC/RACC) | TP5 |
| 9 | Testing basado en sintaxis (mutación, fuzzing) | TP6 |

> Los PDFs de cada capítulo y las notas de cátedra usadas por cada práctico se copian a la carpeta `material/` del práctico correspondiente para que cada TP sea autocontenido.
